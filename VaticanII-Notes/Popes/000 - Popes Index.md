# The Two Popes of Vatican II

> [!summary] One-line
> **John XXIII** opened it (the Architect), **Paul VI** completed it (the Master Builder).

| | [[John XXIII]] | [[Paul VI]] |
|---|---|---|
| Name | Angelo Roncalli | Giovanni Battista Montini |
| Reign | 1958–1963 | 1963–1978 |
| Role | Architect — **called** the Council | Master Builder — **completed** it |
| Signature | *aggiornamento*, "medicine of mercy" | four purposes, held factions together |
| Key act | *Gaudet Mater Ecclesia*; withdrew revelation schema | Nota Praevia; lifted 1054 excommunications |
| Encyclicals | Mater et Magistra, Pacem in Terris | Humanae Vitae (1968) |
| Canonized | 27 Apr 2014 | 14 Oct 2018 |
